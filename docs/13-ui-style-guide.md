# 灯火大排档 UI 风格设计

V5盘面补充：食材从首关11张逐步增加到最多72张，维持现有牌尺寸与奶油材质，不靠缩小牌和图标容纳更多内容。双行、双岛、回环、阶梯桥、灯笼、双峰居中在原食材区并保留孔洞和区域留白。最多八层，共用几何排序和命中，全部遮挡解除才恢复原色。实验室剖面和牌号仅用于开发，不进入玩家局内。

统一风格是**暖夜市、家常小炒、圆润的 2.5D 食物与器物**：深蓝绿夜街衬托红棚布和暖灯笼，蜂蜜与焦糖色木台承托奶油色界面，食物保持鲜亮原色。整体应有小摊的烟火气、食欲和亲近感，同时让材料、订单和操作清楚可辨。

局内基准仍为v12完整交付版；**经营四页的基准更新为2026-11-14用户确认的整体重构视觉稿**，原图完整保存在[四页视觉参考](../reference/lobby-redesign-2026-11-14/)。四页按887×1774原稿画幅绘制，闯关仍使用928×1695，两者各自等比contain，绘制、原生触摸和浏览器无障碍按钮共用对应坐标。

经营首页突出大摊位、大厨与朱红色开张入口；内容页省去品牌区，使用木质结构和奶油内容卡。采用独立环境、摊位物件和可复用空白组件拼装，文字、金币、菜谱份数、拥有／使用中、关卡、活动和按钮行为由真实业务驱动。禁止使用含有按钮、列表槽位或预览效果的整页背景。不是把384、29关、价格600／1000或手动领取写入生产存档。具体交付和差异见[四页接入说明](14-lobby-redesign.md)。

三种工具使用独立的暖奶油纹理美术按钮，文字为“撤回／移出／洗牌”：撤回复用原橙红色立体箭头；移出沿用金色收纳盒；洗牌为橙色交叉箭头与奶油卡片。保持原版细纹理、厚边、高光及深棕手写字，不使用单色线条代替立体图标。视频、一次或已用角标由实时状态绘制。三张移出食材位于备菜标题中部，可逐张取回。素材和提示词见shared/assets/buttons/source/tool-art-v4.md。

订单卡不显示“01桌”等桌号。保留菜名、居中的金币收入、配料与完成进度；当前卡按统一列表顺序排列，下一道在右侧补入，只有列表耗尽后才缩减数量。

## 视觉基准

主品牌固定五字“灯火大排档”：经营首页采用夜空金字，内容页只显示本页标题，闯关继续使用弧形木牌。棚布、灯笼、木架、木台、桌布和凳子共同构成夜市语境；食材、锅盘、金币与按钮使用同一套圆润、略有厚度的表现。背景保留夜街纵深、模糊灯光和暖色反射，前景交互物清晰、明亮，装饰不抢食物和操作的注意力。

画面主要依靠材质和受光形成层次：上部奶油高光，下部蜂蜜或焦糖压暗，接触处有柔和投影。食物形体饱满、特征概括，高光柔和，缩到手机尺寸仍能辨认。锅具保留深灰金属与木柄，金属反光克制。

## 色调与颜色分工

**大面积采用木色和奶油色，深蓝绿承担环境衬底，红色与金色集中在品牌、灯光和关键反馈。** 食材自身的红、绿、橙、黄承担内容辨识，不把每种食材颜色扩展成一套卡片底色。蓝火是厨房的局部冷色点缀。

下表取当前共享绘制的颜色。背景插画的棚布红、灯光和夜街有纹理与受光变化，继续使用原素材，不用单一色块替代。

| 用途 | 颜色 | 使用方式 |
| --- | --- | --- |
| 夜色衬底 | `#253B3B`；局内画布外侧 `#1B3937` | 背景、画幅外留白或场景深处；前景正文使用浅色容器承托。 |
| 奶油面板 | `#FFF5DB → #FFEBC8 → #F5D7A9 → #E0AE73` | 从上到下渐变，停止点为0／25%／80%／100%；用于订单、内容卡和普通面板。 |
| 食材牌与满备菜格 | `#FFF4DA → #FFE9C2 → #EFCF9F` | 停止点为0／55%／100%；所有原色食材共用中性奶油底。 |
| 收入等小挂牌 | `#FFF0CF → #FFE4B7 → #E8BD83` | 停止点为0／50%／100%；面积小、对比清楚，保持轻盈。 |
| 木质面板 | `#E4AA67 → #D99955 → #B97439 → #A65F2B` | 停止点为0／18%／80%／100%；用于木框、木牌及承托结构。 |
| 木台内涂层 | `#B97A43 → #C4864B → #A46230` | 停止点为0／50%／100%，叠低对比木纹；保留背景原有木台外沿。 |
| 正文墨色 | `#60331B`、`#633316` | 深棕色标题、正文和计数，避免在暖底上使用大面积纯黑。 |
| 次级文字 | `#875332`、`#805332` | 标签、说明和次要操作；仍须保持手机尺寸可读。 |
| 品牌与收入强调 | `#B34423`、`#AC4223` | 通关标题、重点金额等局部强调；棚布和主招牌的红色跟随原图。 |
| 金币与奖励 | `#FFF2A0 → #FFD56C → #D5952F` | 通过渐变和高光表现圆润金属，不使用荧光黄铺满面板。 |
| 完成标记 | `#72A33C`，勾线 `#FFF7DC` | 绿色圆底加浅色勾，配合进度或状态文字表达完成。 |
| 新内容轻提示 | `#F2B75E` | 细暖边、短暂提示；不让默认卡片一直高亮。 |
| 奶油与木框亮边 | `#FFF7DF`、`#F8CF94` | 少量内沿高光，帮助表现厚度；通常2～3设计像素。 |
| 炉火 | `#4ED1FF`及素材中的浅蓝高光 | 局限于炉火，不扩展成全局按钮和导航主色。 |
| 弹窗遮罩 | `#21180FBA` | 带棕色的深色遮罩，约73%不透明度，压低背景后突出面板。 |

当前下一关主按钮另用 `#FFE6AF → #F8CC87 → #EAB16A → #D3904C` 蜂蜜渐变，以 `#9D5628` 承托底部厚度。经营页的主操作改为原稿的暖朱红厚按钮；次操作使用奶油色。局内按钮继续保留既有样式。

## 材质与形状

容器使用柔和圆角、浅亮边和向下的投影，形成可触碰的厚度。木质承担外框与承托，奶油色承担信息阅读，金属主要出现在锅、盘盖和金币。木纹只作低对比细节，不穿过文字和食物形成干扰。

以下为现有组件的设计像素，可作为新组件的比例参考，不要求把所有尺寸机械统一：

| 组件 | 现有表现 | 延用方式 |
| --- | --- | --- |
| 普通面板与订单卡 | 圆角约23～30；面板投影 `#51230C55`，模糊10、向下6 | 明亮奶油面与柔和投影成组使用，内部通常不再套多层底板。 |
| 食材牌 | 圆角约短边的18%；底部厚度6；投影 `#69361248`，模糊6、向右2、向下5 | 图案居中，亮边细，保持食物与卡面清楚分离。 |
| 备菜格 | 69×89、圆角18；空槽为凹陷渐变，满槽整格铺奶油色 | 凹槽与满格互斥，满格不能再套一张缩小卡片。 |
| 道具按钮 | 原纹理圆角厚按钮，图标与大字并列，次数为小椭圆角标 | 复用原资源的纹理、体积和组合比例。 |
| 通关面板 | 圆角木质外框、奶油内页、弧形标题木牌、金币装饰 | 层次集中在外框和标题，正文区域保持干净。 |

木台内涂层顺着原背景的椭圆弧边界绘制；扩展场景时同样尊重器物的轮廓和透视。避免厚黑描边、硬直角商务面板、玻璃拟态、霓虹发光边框、过强塑料反光和写实油腻摄影。

## 字体与信息层级

局内字体有圆润、亲切的手写或楷体气质。经营页按文案是否固定、是否属于原稿美术设计来选择实现：品牌、“家常现炒”、固定页标题、固定按钮字样与导航名称可以使用独立美术字图片；固定牌匾可连同字样作为一个逻辑对象保留，不必因为它是中文就强制重画。操作热区、状态与无障碍名称仍由代码维护。金币、关卡、价格、进度、制作份数、动态物品名和状态必须读取真实数据，不能把示例值烘焙进图；是否需要用户输入并不是唯一判断标准。

经营页已将固定页标题、牌匾、页签、导航、开张字样和未改名的原稿首屏菜名恢复为独立美术字。菜名与字图不一致时绘制当前真实文字，不能用旧字图覆盖新名；d03“香菇鸡丁”、d06“鸡蛋炒豆腐”采用这一回退。动态正文采用Noto Sans SC 500子集`LanternBody`，旧标题子集`LanternDisplay`仅保留作源记录，运行不再加载，均附SIL OFL许可。字号、字重、基线和投影按字段标定，不统一套粗体描边。Web、微信与抖音加载同一字体文件并注入实际family；新增动态文案须更新子集和覆盖清单，本轮补齐“烧”字。闯关继续按 `HanziPen SC → Kaiti SC → STKaiti → PingFang SC → sans-serif` 回退，不改变局内基准。

以928×1695设计画布为准，现有字号层级如下：

| 信息 | 当前字号或处理 |
| --- | --- |
| 弧形主招牌 | 使用原背景中的五字美术字，保留其弧度和受光。 |
| 弹窗主标题／核心收入 | 通关标题65，核心收入86；失败标题49。 |
| 主操作 | 下一关48，长文案39；原纹理按钮保留烘焙文字，不再重画一遍。 |
| 页面区块与菜名 | 食材台、订单菜名36。 |
| 常规状态与计数 | 备菜标题32；订单奖励和配料进度经现有辅助函数绘制时至少32。 |
| 收入小挂牌 | “收入”27，金额30；这组紧凑字号独立保留。 |
| 辅助说明与角标 | 多为26～31，先保证可读，再控制占位。 |

新页面先区分标题、主要内容、关键数值、操作和辅助说明，再选择字号。金额或主操作可以突出，说明文字保持克制。长菜名使用 `displayName`；其他长文案应测量字宽，选择换行或合适的短文案，不横向压扁字体，也不为了塞满文字把整页字号不断缩小。

## 组件与状态表达

订单、列表、页签和弹窗应属于同一个小摊：奶油卡承载信息，木框承托区域，图标和食品承担内容辨识。卡片保持足够留白，避免把菜名、价格和每个图标都套入独立小框。

| 场景 | 共用的视觉处理 |
| --- | --- |
| 内容卡 | 奶油渐变、深棕文字、圆角和柔和投影；同级卡默认同权。 |
| 主操作 | 经营页使用原稿朱红厚按钮；局内保留蜂蜜／奶油按钮。图标与动词清楚，每个操作区突出一个主要动作。 |
| 次级操作 | 较轻的奶油小牌或深棕文字，层级低于主按钮。 |
| 选中项 | 局部暖边、底色或字重变化，并保留可辨认的状态标记；整页不同时闪烁。 |
| 已完成 | 绿色勾加数量或文字；菜单已收食材保持原色、原大小、alpha1。 |
| 被遮挡的牌 | 使用暖灰褐、低饱和暗牌，解除全部遮挡后恢复原色；暗牌处理仅服务遮挡状态。 |
| 未解锁或不可用 | 使用明确的锁、条件或不可用文案，可辅以弱化容器；不与“已收到食材”混用同一种灰暗表现。 |
| 未点亮菜谱 | 与已点亮菜谱共用卡片、真实菜名和制作份数，仅菜图置灰；不显示问号或占位菜名，菜品卡仅展示、不响应点击。 |
| 成功弹窗 | 木框、奶油内页、品牌红标题、金币与主结果；次要操作以较轻文字呈现。 |
| 提示与错误 | 使用短句说明当前状态和可执行动作，颜色作为辅助，避免只靠红绿区分。 |

图标延用圆润、略有厚度的器物造型，例如箱子、灯泡、回转箭头、齿轮和扬声器。已有图标优先复用；新增图标需统一光照、圆角和墨色，避免混入 Emoji、系统细线图标或风格不同的素材。

## 布局与页面延用

闯关按“品牌和收入 → 最多三张当前订单 → 食材主体 → 备菜与厨房 → 道具”组织注意力。其他页面延用这种清楚的主次关系：先识别所在页面，再看到主要内容和当前行动，装饰围绕内容展开。

同一页面内所有坐标、字号、描边和阴影使用统一设计空间。经营887×1774与局内928×1695分开计算viewport，切换时同步更新画布与输入变换。背景、绘制和点击共用等比 contain 变换，按安全区与实际胶囊预留空间；声音和设置位于左上。新增组件可按8／16／24／32设计像素组织间距，已定稿组件保留现有精确坐标与小数尺寸。

### 主界面共用规范

四页共享钱包、声音、设置和底部木质导航；金色品牌仅在首页显示。首页独立标题位于107,152,650,140，章节中心Y337，保留两侧金纹并与主标题拉开间距。工具行金币栏208,49,278,77，紧接设置右侧；金额和图标同中心，微信整体避开真实胶囊。右上装饰灯笼是独立单件，并移至右上角，由短绳错落悬挂，不烘焙在环境中。三个内容页去掉品牌和棚沿，保留首页同一真实背景、树叶、灯串及右上灯笼；工具行与Y172的木框奶油内容面保持46设计像素间距；标题共用Y207至271的字框和Y239的云纹中心线。菜谱独立标题改用v17的较轻圆润字形；首排卡在Y476，与浅色标题区保留间距。导航统一Y1611至1774，贴住画布底边。试穿不改变框外页头。

- 深蓝绿环境提供纵深，蜂蜜木色负责承托，奶油面负责阅读；暖朱红集中在当前主操作及选中页签，不给每张卡加红底。
- 同级卡共用底面、圆角和柔和向下投影。卡片、图标、状态角标各自绘制，避免内容内反复套框。
- 四页底部导航位置和热区不变，当前项用浅奶油底与字重表示；导航整行不是一张图片。
- 钱包独立于品牌；大额数值可缩写为万／亿，账本保留完整金额。声音和设置位于左侧，钱包避让真实微信胶囊。素材不包含模拟胶囊。
- 购买、当前装备、选中试装三个状态分别表达；绿色勾表示已装备，朱红细边表示当前选中，“预览中”说明尚未保存。不可只靠颜色区分。

### 设置与动效

声音图标支持真实静音并保存，以深棕斜线表达；六个原创轻音效对应真实取牌、做菜和收钱事件，后台停止，失败不阻塞操作。首页和局内设置共用approved-ui.js的设置组件：标题只写“设置”，“动效”文字与开关放在第一行。开启为正常动效，关闭为减少动效；浏览器使用switch角色与aria-checked表达同一状态。局内随后为同尺寸、同材质的“继续营业／重新开摊／返回首页”，坐标共用game-ui.js，不能另画另一套命中范围。首页只在下方说明自动保存与暂不支持跨设备同步，不展示音效素材、存储实现等开发信息。

### 小摊：先看见自己的摊，再开张

视觉顺序为品牌 → 大摊位和大厨 → 下个愿望 → 开张营业 → 底部导航。场景为主体，保留完整棚布、立柱、木柜、灯笼、锅盘和前景凳子，人物面部不能被招牌或棚沿遮住。普通主题保持统一岸线高度、低栏杆、石岸、干燥木栈道和两侧邻摊，环境美术独立：暖红为河畔夜市，竹影为成片竹林河岸，海风为月夜渔船海港与灯塔，秋夜为枫叶暖灯夜市。不能只换前景或把四套背景合为同图；中景也要有可在缩略图中辨识的差异。环境延续至页面下部，不给场景额外套矩形。

第一锅后在X350 Y1122 W242 H70增加“今日小炒 N/3”奶油次入口，与复访／布置同排且不重叠。已保存牌局时主按钮显示“接着营业”及真实关卡或菜单。

“布置小摊”是轻量次操作；愿望是172高奶油卡，默认展示最近珍藏及真实菜谱进度；首胜优先展示已获星河灯串，主动选择套装后尊重所选金币愿望。标题中心在卡内Y44，金额Y90，进度条Y125至145，底部保留27设计像素；缩略场景上下各留26像素。布置／愿望／开张之间各保留24像素，场景只整体上移12像素，不移动单件。首页只突出一个朱红主按钮，关卡号作为按钮内第二层信息。查看关卡用轻文字入口，不与开张争夺注意力。

**注意：**环境图不得带中央摊位、人物、按钮或愿望卡。大厨、棚布、灯具、桌饰、摆件、菜单牌、锅、盘、背景九个可装扮位置必须独立。换单件只更新对应物件，不能把整个首页换成另一张截图。展示稿中的384金币、29关不是默认档案。

### 装扮：整套购买与珍藏解锁

主标签为“主题套装／珍藏装扮”，位于Y330。预览35,414,817,578，只展示小摊；首页、装扮、相册、购买都等比缩放同一套887×740物件坐标，不再另设横向柜台或独立静物位置。普通套装列表38,1014,804,466，两列186高卡，保持四套完整可见并支持后续纵向扩展。珍藏在Y1008使用“珍藏主题／拥有的”两个固定标签，列表38,1086,804,394；主题卡为单列174高卡，只含主题图、名称、件数和进度条。

拥有列表按主题分组，组内两列174高卡、186行距，只列已经获得的部件。点卡试穿，下方Y1500至1588的朱红按钮确认换上；卡片不重复“点击试穿”，已拥有套装不重复“可免费换上”。选中使用中的部件显示奶油次级按钮“换下物品名”，恢复普通套装相应部位，其余装备不变。预览旁“恢复当前装扮”取消未保存效果。珍藏获取弹窗采用两列九张部件卡，每卡含缩略图、部位、条件／已获得及进度条；卡片只读。

装扮的普通入口默认进入主题套装，并保留当前真实装扮；点卡才开始试装。暖红卡标已拥有／使用中，普通套装卡展示名称、缺件总价和旧件抵扣提示，不再展开单件商架。购买入口及确认始终显示实际需付金额。珍藏主题卡负责整套试穿与收集展示，拥有列表负责单件试穿和明确确认；切换标签先回到实际穿着，避免把未获得的整套预览当作已保存装备。

预览图片内统一使用“当前使用的装扮／试穿中·未保存”的奶油色纯文字，带轻暗影，位于图片左上，无底板、描边、厚度或热区；不可复用奶油按钮。主题卡的朱红选中边、预览说明、拥有部件的绿色使用标记分开表达。收集说明关闭后保留原预览；普通套装、珍藏整套和已拥有部件统一为点卡试穿、按钮换上；试穿可直接切卡，预览旁提供正常尺寸“恢复当前装扮”，切页清除，均不提前写档。使用中的珍藏部件通过奶油“换下”按钮恢复普通套装对应部位；无动作状态用轻提示，不保留醒目红色伪按钮。

首胜赠礼使用现有星河灯串单件，展示实物和永久拥有说明；先试穿，再明确点击“换上”。不把暖红完整场景改为空摊。

星河琉璃使用青玉琉璃曲檐、靛蓝织物、鎏金星纹与八角宫灯；柿灯丰年使用竹编棚、柿子花灯、米麻织物、叶边陶盘和暖木。每组包括独立环境、棚顶、灯具、桌椅、盆栽、菜单、餐盘、锅具和厨师，桌布归桌椅。九件源图来自内置imagegen制作，单件从源图集显式提取后写入独立清单；v14另补绘独立厨师与浅视角锅具，使普通／珍藏混搭共用同一持锅关系；正常构建不读取概念稿或源图集。固定木架、牌匾、完整备菜架、菜肴和炉火继续按既定层级组合。牌匾顶端对齐棚顶Y30，餐盘上移到台面，相框避开右柱脚，两种窗口同步生效。

局内主题背景复用首页的完整887×1774镜头，按游戏宽度整体等比缩放、顶部对齐，仅由局内窗口露出顶部一小段，不单独取中景或缩小整幅背景。局内采用去除可换物件的纯环境／木台底层，叠加实际装备棚沿、灯具、凳子、桌布与品牌。底部木台连续贴底，桌布覆盖右侧台面与前沿并随画框裁切，保留小面积露出；不增加悬空暗槽。厨房沿用原锅体运动轮廓，珍藏锅柄表达相应材质与图案；珍藏餐盘底面参与真实出菜绘制。两端共享实现和运行素材。

### 菜谱：食物是主体，卡面只承托

结构为页标题与收集进度 → 菜谱／成就／相册 → 内容 → 翻页。菜谱保持两列三行，无夹子，不套材料卡；使用独立成品透明图、共用奶油卡、原生菜名与制作次数。20道菜全部按数据分页，最后一页只有实际剩余两道，不预画四个空卡框。菜名优先使用配置的短名，长文字省略或换行，不缩扁。

页签底面完整置于浅木色标题区内，并与下方棕色内容区留出间隔。页签字图按可见边界居中；动态文字按实际字形高度居中，不能仅依赖字体em框的middle基线。钱包图标与金额、奖励名与获得状态、页脚说明与两侧纹样分别共用一条中心线。

“家常菜谱”按同级页标题缩至约66设计像素的可见字高，保留原稿字样等比绘制；云纹随标题居中。收集进度单独一行，使用较轻的44高标签与27号正文，与标题、下方页签分别保留约20、15设计像素间距，三个菜谱子页共用此标题区。

未收集的成品图片置灰，已经点亮的成品保持原色；两者正常显示真实菜名与“已做N份”。菜品卡仅展示，不设点击入口或介绍弹窗。成就用同级信息卡表达真实进度。相册只为真实照片／纪念创建缩略卡，空相册显示说明；照片按拍摄时的装备快照绘制，不跟随当前换装改变。

**注意：**成品图只包含食品及其餐盘，不得包含卡面、菜名或次数。禁止将前六道菜及其列表背景烘焙成整张图。各子页容器和按钮随内容创建，不能靠大色块遮住另一子页的固定图案。

### 夜市：氛围在横幅，规则在卡片

结构为页标题 → 当期／往期／每日 → 活动横幅 → 当前活动册大卡 → 其他册的紧凑行卡。横幅用独立环境、灯笼和实时文字组合，低对比环境衬亮字。当前册以大图标、册名、进度、奖励和一个主动作建立焦点，后续册降低权重；统一卡面和对齐线，避免四张卡同时高亮。

当前册与后续行卡使用同一份活动数据，开放条件、已完成、已选中和奖励状态分别表达。每日页优先展示日期、三道短菜单、真实菜图／菜名、份数、一次金币奖励和开炒按钮，底部保留每日奖励状态。每日页用独立任务行，不在当期页面的固定底图上盖一层纸。往期保留已开放册，内容随真实记录变化。

**注意：**活动背景不得画死册名、进度条、按钮或四个列表槽。奖励在真实进度达到条件时自动发放，界面使用“查看已获奖励／继续营业攒进度”，不得引入手动领取或重复发放。参考稿周次和奖励仅作排版示例，实际开放期由配置计算。

### 资源边界与拼装规则

生产资源按可维护的逻辑图层组织。组件可以包含自己的亮边、阴影和空白内页；固定柜台与立柱可为一个结构件，不变化且具有相同遮挡关系的台面静物也可保留在同一插画组内。不要为了拆分而将原稿装饰全部重画，造成细节丢失。只要元素有独立交互、动态数据、换装、显示隐藏或动画，就必须独立；静态场景组也不能带入UI控件、固定列表槽或示例数据。

| 层级 | 可包含 | 不可包含 |
| --- | --- | --- |
| 纯环境 | 夜街、水面、远摊、固定树木和环境灯光 | 中央可换装摊位、人物、钱包、按钮、卡片、进度条 |
| 场景物件 | 单个柜台结构、棚布、灯笼、大厨、凳子、锅盘、摆件 | UI边框、分类页签、当前价格／状态、其他装备部位 |
| UI底面 | 一个空白按钮／卡片／木框／选中页签的材质和阴影 | 兄弟控件、列表位置、成品、名称、价格和模拟状态 |
| 品牌 | 固定弧形五字“灯火大排档”及其木牌 | 钱包、页标题、关卡、系统胶囊 |
| 内容与反馈 | 独立食物、图标；代码绘制的文字、勾、进度和选中边 | 作为整页背景固定下来的一组交互内容 |

绘制顺序：纯环境 → 场景／内容父容器 → 子物件和卡片 → 图标与真实文字／状态 → 钱包和导航 → 弹层。场景内部有明确基础清单和前后遮挡层，柜台后层 → 大厨 → 柜台前沿，皮肤替换原层而不重建其他层；挂点、落地点来自同一基础组合。物件按contain等比绘制并保留注册锚点，不能换皮后各自重新居中；透明开口保留alpha。按钮与卡片采用九切片，只伸展空白中心和边条，圆角与高光不拉长。大容器的弧顶由其自身上部切片保留，内部布局不随图片缩放。

完整性验收先核对母版元素清单，再把所有基础层复合与原稿对照，通过后才制作换装层。单张合成稿没有保存被遮挡像素，需要补画时只补底层必要区域；重复在完整母版上叠加一张新皮肤会留下旧物件边缘，不能作为正式换装方案。备菜架/蒸笼/蔬菜合为完整静物组，当前22层固定／换装检查入口见14文档；通过图层检查不替代原稿视觉核对。

资源清单位于`shared/assets/lobby/manifest.json`，独立源图位于`source/ui/`、`source/scene/`、`source/brand/`、`source/icons/`。`prepare-lobby-assets.py`仅按清单缩放、压缩和导出颜色变体，不读取参考稿、不裁整页坐标、不合成页面。页面坐标在`lobby-layout.js`，共用底面在`lobby-components.js`，场景在`lobby-scene.js`，功能组装在`lobby-ui.js`。四张完整视觉稿只放在`reference/`作对照，不进入运行包。

主题可改变夜色和九个装扮部位，保持奶油信息面、食物原色和深棕文字。四套普通主题以reference/theme-suites-2026-11-16中的确认图为准：暖红为朱红／奶油配暖白花灯、红凳和深绿波纹陶盆；海风为藏蓝／象牙白配细浪纹、暖白蓝筋灯及青花器物；竹影为浅竹绿／橄榄绿／奶油配疏朗竹叶；秋夜为低饱和梅紫／奶油配小金色四瓣花。蜂蜜木架、肤色、奶油衣帽、绿叶和食物不染色。source/scene/v16按部件独立制作对应纹样、材质与透明边界，优先读取manifest显式素材，禁止用通用滤色冒充已确认主题；palettes.json仅作为未提供专用素材时的材质回退。

## 动效语言

动效表现器物的轻抬、落稳、收起、颠锅和上菜：短、柔和、有方向，反馈与真实操作和状态对应。避免持续大幅弹跳、无意义旋转、全屏闪光，以及等待动画结束才允许继续操作。

- 取牌沿弧线飞向备菜格，卡面尺寸平滑变化，食物保持等比；点击圈只作反馈。
- 收到食材时绿勾轻弹，食物保持原色；交单后才出现盘盖，随后整卡收起，新单轻落。
- 制作依靠颠锅、碎料和轻蒸汽表达热气；上菜副本独立飞行，收入在真实送达后轻弹。
- 小反馈控制在约0.16～0.30秒；收入回弹峰值仅1.018。弹窗约0.34秒从0.94缩放至1，配合淡入。
- 减少动效时保留结果和状态辨识，降低位移、旋转与粒子运动；暂停和后台冻结表现。

闯关各阶段的精确时长、路径、图层与并发规则只在[菜单交接时序和表现](10-menu-handoff.md)维护。新页面延用手感，不复制演示常量或另外引入阻塞业务的动画等待。

## 交付检查

新增界面完成后，至少核对以下项目：

1. 与当前闯关并排查看，奶油色、木色、墨色、圆角、亮边、阴影和图标属于同一套风格；主招牌仍为五字。
2. 主内容与主操作清楚，装饰不遮挡信息；已收、选中、锁定和不可用状态可以区分。
3. 图片和文字不拉伸，食物清晰，长文案不溢出；在手机尺寸查看字号与实际点击范围。
4. 检查正常、选中、不可用、空内容和弹窗状态，以及减少动效后的状态辨识；页面只检查实际存在的功能状态。
5. 单独查看每张生产素材：按钮不含文字、卡面不含列表、环境不含功能；改变列表数量、页签和单件装备时无旧图残留。
