# 灯火大排档 UI 风格设计

统一风格是**暖夜市、家常小炒、圆润的 2.5D 食物与器物**：深蓝绿夜街衬托红棚布和暖灯笼，蜂蜜与焦糖色木台承托奶油色界面，食物保持鲜亮原色。整体应有小摊的烟火气、食欲和亲近感，同时让材料、订单和操作清楚可辨。

基准为2026-11-14已落地的 v12 完整交付版闯关 UI。新增或改造小摊、装扮、菜谱、夜市等页面时，延用本文的色彩、材质、组件与动效语言；这些页面的现状不代表已经全部完成风格统一。页面功能与导航遵循[经营需求与验收](11-product-requirements.md)，闯关坐标、时序和状态遵循[菜单交接时序和表现](10-menu-handoff.md)。

## 视觉基准

主招牌固定为弧形五字“灯火大排档”。棚布、灯笼、木架、木台、桌布和凳子共同构成夜市语境；食材、锅盘、金币与按钮使用同一套圆润、略有厚度的表现。背景保留夜街纵深、模糊灯光和暖色反射，前景交互物清晰、明亮，装饰不抢食物和操作的注意力。

画面主要依靠材质和受光形成层次：上部奶油高光，下部蜂蜜或焦糖压暗，接触处有柔和投影。食物形体饱满、特征概括，高光柔和，缩到手机尺寸仍能辨认。锅具保留深灰金属与木柄，金属反光克制。

查看效果时，优先使用本工程当前取样：

- [闯关全屏](../previews/ui-v12-game.png)、[真实结算](../previews/ui-v12-result.png)：观察材质、比例和信息层级。
- [完整流程](../previews/ui-v12-flow.png)：观察选料、交单、做菜、上菜与反馈节奏。
- [交付版与共享渲染对照](../previews/ui-v12-comparison.png)、[微信模拟器](../previews/ui-v12-wechat-game.png)：核对组件和平台适配。

旧 v13 底图、旧演示和素材图鉴的排版不作为新页面的风格基准。不要沿用其中过时的收入目标、永久首卡高亮或厨房挂牌。

## 色调与颜色分工

**大面积采用木色和奶油色，深蓝绿承担环境衬底，红色与金色集中在品牌、灯光和关键反馈。** 食材自身的红、绿、橙、黄承担内容辨识，不把每种食材颜色扩展成一套卡片底色。蓝火是厨房的局部冷色点缀。

下表取当前共享绘制的颜色。背景插画的棚布红、灯光和夜街有纹理与受光变化，继续使用原素材，不用单一色块替代。

| 用途 | 颜色 | 使用方式 |
| --- | --- | --- |
| 夜色衬底 | `#253B3B`；局内画布外侧 `#1B3937` | 背景、画幅外留白或场景深处；前景正文使用浅色容器承托。 |
| 奶油面板 | `#FFF5DB → #FFEBC8 → #F5D7A9 → #E0AE73` | 从上到下渐变，停止点为0／25%／80%／100%；用于订单、内容卡和普通面板。 |
| 食材牌与满备菜格 | `#FFF4DA → #FFE9C2 → #EFCF9F` | 停止点为0／55%／100%；所有原色食材共用中性奶油底。 |
| 收入等小挂牌 | `#FFF0CF → #FFE4B7 → #E8BD83` | 停止点为0／50%／100%；面积小、对比清楚，保持轻盈。 |
| 木质面板 | `#E4AA67 → #D99955 → #B97439 → #A65F2B` | 停止点为0／18%／80%／100%；用于木框、木牌及承托结构。 |
| 木台内涂层 | `#B97A43 → #C4864B → #A46230` | 停止点为0／50%／100%，叠低对比木纹；保留背景原有木台外沿。 |
| 正文墨色 | `#60331B`、`#633316` | 深棕色标题、正文和计数，避免在暖底上使用大面积纯黑。 |
| 次级文字 | `#875332`、`#805332` | 标签、说明和次要操作；仍须保持手机尺寸可读。 |
| 品牌与收入强调 | `#B34423`、`#AC4223` | 通关标题、重点金额等局部强调；棚布和主招牌的红色跟随原图。 |
| 金币与奖励 | `#FFF2A0 → #FFD56C → #D5952F` | 通过渐变和高光表现圆润金属，不使用荧光黄铺满面板。 |
| 完成标记 | `#72A33C`，勾线 `#FFF7DC` | 绿色圆底加浅色勾，配合进度或状态文字表达完成。 |
| 新内容轻提示 | `#F2B75E` | 细暖边、短暂提示；不让默认卡片一直高亮。 |
| 奶油与木框亮边 | `#FFF7DF`、`#F8CF94` | 少量内沿高光，帮助表现厚度；通常2～3设计像素。 |
| 炉火 | `#4ED1FF`及素材中的浅蓝高光 | 局限于炉火，不扩展成全局按钮和导航主色。 |
| 弹窗遮罩 | `#21180FBA` | 带棕色的深色遮罩，约73%不透明度，压低背景后突出面板。 |

当前下一关主按钮另用 `#FFE6AF → #F8CC87 → #EAB16A → #D3904C` 蜂蜜渐变，以 `#9D5628` 承托底部厚度。新增主操作优先延用这种做法，不靠提高饱和度区分。

## 材质与形状

容器使用柔和圆角、浅亮边和向下的投影，形成可触碰的厚度。木质承担外框与承托，奶油色承担信息阅读，金属主要出现在锅、盘盖和金币。木纹只作低对比细节，不穿过文字和食物形成干扰。

以下为现有组件的设计像素，可作为新组件的比例参考，不要求把所有尺寸机械统一：

| 组件 | 现有表现 | 延用方式 |
| --- | --- | --- |
| 普通面板与订单卡 | 圆角约23～30；面板投影 `#51230C55`，模糊10、向下6 | 明亮奶油面与柔和投影成组使用，内部通常不再套多层底板。 |
| 食材牌 | 圆角约短边的18%；底部厚度6；投影 `#69361248`，模糊6、向右2、向下5 | 图案居中，亮边细，保持食物与卡面清楚分离。 |
| 备菜格 | 69×89、圆角18；空槽为凹陷渐变，满槽整格铺奶油色 | 凹槽与满格互斥，满格不能再套一张缩小卡片。 |
| 道具按钮 | 原纹理圆角厚按钮，图标与大字并列，次数为小椭圆角标 | 复用原资源的纹理、体积和组合比例。 |
| 通关面板 | 圆角木质外框、奶油内页、弧形标题木牌、金币装饰 | 层次集中在外框和标题，正文区域保持干净。 |

木台内涂层顺着原背景的椭圆弧边界绘制；扩展场景时同样尊重器物的轮廓和透视。避免厚黑描边、硬直角商务面板、玻璃拟态、霓虹发光边框、过强塑料反光和写实油腻摄影。

## 字体与信息层级

字体应有圆润、亲切的中文手写或楷体气质，常用字重为600～700。当前闯关绘制按 `HanziPen SC → Kaiti SC → STKaiti → PingFang SC → sans-serif` 回退；跨平台补充字体时，可参考[设计令牌](../shared/data/design-tokens.json)中的 `Microsoft YaHei`、`Noto Sans CJK SC`。字体实际可用性和字宽需要在目标设备核对。

以928×1695设计画布为准，现有字号层级如下：

| 信息 | 当前字号或处理 |
| --- | --- |
| 弧形主招牌 | 使用原背景中的五字美术字，保留其弧度和受光。 |
| 弹窗主标题／核心收入 | 通关标题65，核心收入86；失败标题49。 |
| 主操作 | 下一关48，长文案39；原纹理按钮保留烘焙文字，不再重画一遍。 |
| 页面区块与菜名 | 食材台、订单菜名36。 |
| 常规状态与计数 | 备菜标题32；桌号、订单奖励和配料进度经现有辅助函数绘制时至少32。 |
| 收入小挂牌 | “收入”27，金额30；这组紧凑字号独立保留。 |
| 辅助说明与角标 | 多为26～31，先保证可读，再控制占位。 |

新页面先区分标题、主要内容、关键数值、操作和辅助说明，再选择字号。金额或主操作可以突出，说明文字保持克制。长菜名使用 `displayName`；其他长文案应测量字宽，选择换行或合适的短文案，不横向压扁字体，也不为了塞满文字把整页字号不断缩小。

## 组件与状态表达

订单、列表、页签和弹窗应属于同一个小摊：奶油卡承载信息，木框承托区域，图标和食品承担内容辨识。卡片保持足够留白，避免把菜名、价格和每个图标都套入独立小框。

| 场景 | 共用的视觉处理 |
| --- | --- |
| 内容卡 | 奶油渐变、深棕文字、圆角和柔和投影；同级卡默认同权。 |
| 主操作 | 蜂蜜或奶油厚按钮，图标与动词清楚；每个操作区突出一个主要动作。 |
| 次级操作 | 较轻的奶油小牌或深棕文字，层级低于主按钮。 |
| 选中项 | 局部暖边、底色或字重变化，并保留可辨认的状态标记；整页不同时闪烁。 |
| 已完成 | 绿色勾加数量或文字；菜单已收食材保持原色、原大小、alpha1。 |
| 被遮挡的牌 | 使用暖灰褐、低饱和暗牌，解除全部遮挡后恢复原色；暗牌处理仅服务遮挡状态。 |
| 未解锁或不可用 | 使用明确的锁、条件或不可用文案，可辅以弱化容器；不与“已收到食材”混用同一种灰暗表现。 |
| 成功弹窗 | 木框、奶油内页、品牌红标题、金币与主结果；次要操作以较轻文字呈现。 |
| 提示与错误 | 使用短句说明当前状态和可执行动作，颜色作为辅助，避免只靠红绿区分。 |

图标延用圆润、略有厚度的器物造型，例如箱子、灯泡、回转箭头、齿轮和扬声器。已有图标优先复用；新增图标需统一光照、圆角和墨色，避免混入 Emoji、系统细线图标或风格不同的素材。

## 布局与页面延用

闯关按“品牌和收入 → 三桌订单 → 食材主体 → 备菜与厨房 → 道具”组织注意力。其他页面延用这种清楚的主次关系：先识别所在页面，再看到主要内容和当前行动，装饰围绕内容展开。

所有坐标、字号、描边和阴影都使用统一设计空间。背景、绘制和点击共用等比 contain 变换，按安全区与实际胶囊预留空间；声音和设置位于左上。新增组件可按8／16／24／32设计像素组织间距，已定稿组件保留现有精确坐标与小数尺寸。

新页面按以下方向延用风格，功能和导航仍以11、12文档为准：

| 页面 | 延用方向 |
| --- | --- |
| 小摊 | 保留暖灯、棚布、招牌和场景纵深；愿望、钱包和开摊操作使用奶油牌与蜂蜜按钮，主要行动清楚。 |
| 装扮 | 以场景或厨房预览为主体，物品用奶油卡承载；金币、拥有和装备状态沿用统一角标及勾选语言。 |
| 菜谱 | 让原色成品和配方成为主体，使用奶油卡或内页、木质标题；避免把菜谱做成密集数据面板。 |
| 夜市 | 用夜色、灯笼和主题场景体现氛围，册页与任务内容仍用奶油色阅读面，奖励以金币或暖金局部强调。 |

主题可以改变夜色、棚布、灯具、木台、摆件和锅盘装饰；保持奶油信息面、食物原色、深棕文字和完成状态的辨识。外观变化不移动关键操作、不增加玩法暗示，也不改变奖励、容量、配方或时间规则。

## 动效语言

动效表现器物的轻抬、落稳、收起、颠锅和上菜：短、柔和、有方向，反馈与真实操作和状态对应。避免持续大幅弹跳、无意义旋转、全屏闪光，以及等待动画结束才允许继续操作。

- 取牌沿弧线飞向备菜格，卡面尺寸平滑变化，食物保持等比；点击圈只作反馈。
- 收到食材时绿勾轻弹，食物保持原色；交单后才出现盘盖，随后整卡收起，新单轻落。
- 制作依靠颠锅、碎料和轻蒸汽表达热气；上菜副本独立飞行，收入在真实送达后轻弹。
- 小反馈控制在约0.16～0.30秒；收入回弹峰值仅1.018。弹窗约0.34秒从0.94缩放至1，配合淡入。
- 减少动效时保留结果和状态辨识，降低位移、旋转与粒子运动；暂停和后台冻结表现。

闯关各阶段的精确时长、路径、图层与并发规则只在[菜单交接时序和表现](10-menu-handoff.md)维护。新页面延用手感，不复制演示常量或另外引入阻塞业务的动画等待。

## 交付检查

新增界面完成后，至少核对以下项目：

1. 与当前闯关并排查看，奶油色、木色、墨色、圆角、亮边、阴影和图标属于同一套风格；主招牌仍为五字。
2. 主内容与主操作清楚，装饰不遮挡信息；已收、选中、锁定和不可用状态可以区分。
3. 图片和文字不拉伸，食物清晰，长文案不溢出；在手机尺寸查看字号与实际点击范围。
4. 检查正常、选中、不可用、空内容和弹窗状态，以及减少动效后的状态辨识；页面只检查实际存在的功能状态。
5. 浏览器和微信使用同一设计坐标与资源，核对安全区、胶囊、触摸、遮挡关系和重复叠画；自动截图不能代替真机验收。

更改统一视觉基准时，同步修订本文及相关实现，替换过时规则；精确闯关时序同步维护10文档，产品功能变化同步维护11、12文档。
