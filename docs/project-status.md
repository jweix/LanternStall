# 项目现状与接手记录

适用日期：2026-11-21。当前规则与实现以本文、[关卡配置与验证](09-level-generation.md)、[菜单交接](10-menu-handoff.md)和源码为准；`docs/handoff/` 中的 PDF、DOCX、旧截图属于历史交接材料。

## 当前玩法与关卡

20 道菜、14 种食材，统一菜品列表的前三道共享七格备菜，配齐立即做菜，送达才结算。没有收入目标和速度评星；全部材料消耗、厨房与最后送达均完成才通关。菜单交接使用独立任务和收入快照，飞行不锁输入，后台暂停不计时。

V5 关卡由 `shared/data/level-config.js` 配置统一扁平菜品列表、形状、层数、难度档和种子。最多三张当前卡，任意完成一道补入下一道，列表耗尽后数量只减不增，卡面不显示桌号。首关沿用原第2关五份菜、十一张牌；第9关达到二十四份菜，上限为最多二十四份菜、六种配方、七十二张牌和八层。六种轮廓保留空洞与独立区域，几何遮挡、绘制和触摸共用规则。全关和开局材料集中度受限，生成必须通过真实引擎无道具通关回放。前六十关逐关配置，后续使用五个封顶菜单及精选种子库循环；有限内容不等于无限独立关卡。

离线分析支持四种策略、零道具/各一次免费测试/最多一至三次视频、三态求解、容量和安全选择范围、候选筛选、失败记录复现。浏览器实验室提供配置预览、分层观察和真实回放，不读写经营存档。配置方式、命令、当前策略结果及适用边界见 [09 文档](09-level-generation.md)。

道具关已有可配置实验生成模式`tool-gate`：从菜单、形状、层数与种子自动分配材料，首道菜容量无解证书和一次移出真实通关回放双重验收。两个配置示例在`configs/experiments/`，`levels:generate:tool-gate`可批量输出并导入实验室；66个生成结果专项回归覆盖14／17／18张、7／8层、三种形状及不同菜单。固定TG01的255个真实稳定状态穷举仍独立保留。字段、使用方式和边界见[生成说明](16-tool-gate-generation.md)。本模式仅支持首道之前的一次移出门槛，不接主线或native包；正式广告仍未接通，主线无道具见证口径不变。

## 经营与平台

四页经营包含小摊、装扮、菜谱、夜市，使用已确认的 887×1774 参考稿和独立素材。共享事务维护金币、装备、收藏、活动和首通；各端本机 `lantern-stall-v2` 存档，不含账户或云同步。详情见 [需求](11-product-requirements.md)、[经济](12-operations-and-economy.md)、[视觉接入](14-lobby-redesign.md)。

抖音首发，保留微信与 Web。native两端共享核心、资源、字体和构建，生成目录不手改；静态UI数据紧凑导出，正文字体省去未使用的竖排度量，包体仍接近项目4MiB预算。侧边栏已接主页／设置入口、三步引导、跳转与最新来源识别，每日200金币自动到账，金币与发奖日持久化去重；自动回归覆盖冷／热启动、异步能力检查、存档失败、跨日／回拨和局中返回。当前环境缺少可用douyinide，启动协议返回无兼容应用，IDE／真机闭环与必接审核仍待验收。注册、导入与测试步骤见[15文档](15-douyin-launch.md)。

激励视频救援适配已接入，撤回最近一张、移出前三张和洗牌各一次，主线通过视频领取，不再附送求解步骤；只有完整播放回调才发奖，并隔离旧局、取消、错误和重复回调。两端 `src/ad-config.js` 的真实广告单元仍为空，入口因此隐藏。正式AppID `tt727304ceec0e853e02`已配置；真实广告、正式账号权限、真机和发布仍待验收。

## 验证与边界

V5 已通过一万组关卡/种子扩样、首关 387 个稳定状态穷举、统一队列 64 个完成集合穷举、108 条模型与真实引擎逐步差分、快速连续输入、工具和广告回调隔离，以及 27 个绘制与触摸变换用例。完整构建及核心、菜单交接、经营、微信和抖音自动回归均已通过。第1–100关通过64次策略目标检查，并独立复核第1–20、40、60、64关；不能代替真人难度和广告转化验收。

浏览器已实点 V5 新首关：先完成中间菜仍补满三道，列表耗尽后依次显示两道、一道、零道；卡面无桌号，最终十一张食材全部消耗、收入 205 并通关，控制台无警告或错误。配置编辑可同步改变菜谱、材料和实际收入。自动回归使用 SDK 模拟，不等同于开发者工具或手机结果。留存版已验证手机尺寸浏览器的首胜换装、每日菜单和刷新后同局恢复；两端IDE与真机仍未验收；真机音频、性能、真人校准、账号云同步、资质和发布仍待推进。

## 留存体验与接入边界

首胜点亮3道菜谱赠星河灯串，明确试穿、装备并保存。竹影1800、海风9000、秋夜16000金币，旧档保留。前期舒缓与挑战交替，独立样本第3关贪心96.88%、第6–8关77.60%，仅代表模型。第一锅后开放菜谱、活动和每日三份5／6／7菜短菜单，奖励120／160／200各一次；不推进主线，不重复发流水，首次完成可累计收藏与活动。30／100份菜生成纪念贴纸。

续玩保存内容指纹、有效用时和真实操作历史，恢复预约、暂存、厨房及已用道具，沿用尝试编号保证结算一次。重开／换关仍清空旧任务。六种原创轻音效、静音保存和后台停止已接三端，无背景音乐。两端SDK可用时调用reportAnalytics，后台事件配置和真机数据仍待验收。save注入接口可承接后续服务端事务，但目前无账号、云冲突策略和真实留存报表，不能称为已接云同步。下一步需要后端信息与真人队列，验证前期到达、首次装备、第二次开局及D1／D7有效回访。
