# 项目现状与接手记录

适用日期：2026-11-18。当前规则与实现以本文、[关卡配置与验证](09-level-generation.md)、[菜单交接](10-menu-handoff.md)和源码为准；`docs/handoff/` 中的 PDF、DOCX、旧截图属于历史交接材料。

## 当前玩法与关卡

20 道菜、14 种食材，三桌有限订单共享七格备菜，配齐立即做菜，送达才结算。没有收入目标和速度评星；全部材料消耗、厨房与最后送达均完成才通关。菜单交接使用独立任务和收入快照，飞行不锁输入，后台暂停不计时。

V3 关卡由 `shared/data/level-config.js` 配置三桌完整菜谱队列、形状、层数、难度档和种子。首关四份菜、八张牌；逐步增长至最多二十四份菜、六种配方、七十二张牌和五层。六种轮廓保留空洞与独立区域，几何遮挡、绘制和触摸共用规则。全关和开局材料集中度受限，生成必须通过真实引擎无道具通关回放。前六十关逐关配置，后续使用五个封顶菜单及精选种子库循环；有限内容不等于无限独立关卡。

离线分析支持四种策略、零道具/免费/一次/两次额外救援、三态求解、容量和安全选择范围、候选筛选、失败记录复现。浏览器实验室提供配置预览、分层观察和真实回放，不读写经营存档。配置方式、命令、当前策略结果及适用边界见 [09 文档](09-level-generation.md)。

## 经营与平台

四页经营包含小摊、装扮、菜谱、夜市，使用已确认的 887×1774 参考稿和独立素材。共享事务维护金币、装备、收藏、活动和首通；各端本机 `lantern-stall-v2` 存档，不含账户或云同步。详情见 [需求](11-product-requirements.md)、[经济](12-operations-and-economy.md)、[视觉接入](14-lobby-redesign.md)。

抖音首发，保留微信与 Web。native 两端共享核心、资源、字体和构建，生成目录不手改；包体接近项目的 4 MiB 预算。抖音注册、导入目录与侧边栏边界见 [15 文档](15-douyin-launch.md)。侧边栏已有设置入口、跳转与来源识别，未接礼包，不代表完成必接审核。

激励视频救援适配已接入，按已验证续解路线提供撤回或暂存，每局最多两次；只有完整播放回调才发奖，并隔离旧局、取消、错误和重复回调。两端 `src/ad-config.js` 的真实广告单元仍为空，入口因此隐藏。未完成真实广告、正式 AppID、真机和发布验收。

## 验证与边界

V3 已通过一万组关卡/种子扩样、首关 256 个稳定状态穷举、108 条模型与真实引擎逐步差分、快速连续输入、工具和广告回调隔离，以及 27 个绘制与触摸变换用例。原有核心、菜单交接、经营、微信和抖音回归继续执行。当前精选关卡的贪心策略阶段通过率有下降梯度，不能代替真人难度和广告转化验收。

浏览器已核对首关八张牌、第六十四关五层双峰与七十二张牌，并用完整见证回放至通关；配置编辑可同步改变菜谱、材料和实际收入。自动回归使用 SDK 模拟，不等同于开发者工具或手机结果。本次 V3 尚未执行两端 IDE 与真机验证；音频、性能、真人校准、账号云同步、资质和发布仍待推进。
