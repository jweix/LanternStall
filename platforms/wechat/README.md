# 微信小游戏

AppID：`wx09cfd51ad5bcdb2f`。

在仓库根目录执行 `npm run build:wechat`，再把本目录导入微信开发者工具。`project.config.json` 指向生成的 `game/`；不要导入整个仓库，也不要只导入 `src/`。

代码在 `src/`，公共业务与素材在仓库的 `shared/`。生成目录不提交 Git，不能手改。重新拉取仓库后先构建。

当前可操作试玩支持完整做菜与消除流程。收入仅累计记录；用完全部食材并等最后一道菜上桌后通关。关卡进度只在本机保存，暂不保存中途牌局。音频和正式发布接入未完成。

运行和验证的详细步骤见根目录 `README.md`。
