# 主界面独立生产素材

此目录按游戏资源组织，`source/`中每个文件只含一个逻辑对象或材质。完整四页视觉稿位于`reference/lobby-redesign-2026-11-14/`，仅供对照；没有`decor-clean.png`、整页皮肤、带按钮的环境或带实时预览的列表背景。

| 子目录 | 内容 | 可变内容在哪里 |
| --- | --- | --- |
| `source/scene/` | 纯河岸环境、空柜台及固定立柱、半身大厨、棚布、单凳、五种独立灯具 | 实时组合器`lobby-scene.js`独立放置／替换，UI不在这些图里 |
| `source/ui/` | 无字主／次按钮、选中／普通页签、奶油卡、空白内容面、纯木纹 | `lobby-components.js`九切片，`lobby-ui.js`创建实际控件、状态与文案 |
| `source/brand/` | 固定五字弧形品牌和顶部棚沿（从独立棚布取檐口） | 品牌不带钱包、页标题或系统胶囊 |
| `source/icons/` | 金币、声音与设置图形 | 按钮底、图标和实际热区独立 |

`manifest.json`记录语义ID、路径、导出尺寸、九切片和完整生成提示词。新增大厨、柜台、棚布、凳子、透明海风灯笼和空白内容框由内置图像生成工具按单物件提示制作；其余固定品牌、空白皮肤／图标从确认参考中独立提取清理，透明区域不含其他功能。纯环境来自用户提供的空夜市背景。锅盘、菜单牌、摆件和其余主题环境复用`shared/assets/stall/source/`的独立美术。

构建脚本`prepare-lobby-assets.py`只按清单读独立文件、等比缩放、压缩导出并为衣料、棚布、凳子生成颜色变体。不读取参考稿、不进行整页裁切、不合成UI截图。颜色变体限制在对应物件的红色材质区域；人物只改围裙区域，保留肤色与厨师服。透明PNG保留alpha，环境JPEG不含交互区域。

布局及场景锚点在`shared/data/lobby-layout.js`；UI组件只拉伸九切片中间，物件等比放置。修改源素材或清单后重新构建，不手改`shared/assets/runtime/`和微信生成目录。查看`previews/lobby-v4-components.png`检查拆分边界，页面验收与维护规则见`docs/13-ui-style-guide.md`和`docs/14-lobby-redesign.md`。
